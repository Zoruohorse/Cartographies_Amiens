# Cartographie Ligne THT Amiens – Petit-Caux
Dépôt statique prêt pour GitHub Pages. Importer le contenu à la racine puis activer Pages sur `main / root`.
- `apps/cards/` : cartes d’acteurs
- `apps/network/` : réseau interactif
- `data/` : référentiel partagé
Test local : `python3 -m http.server 8000`
Validation : `python3 validate.py`
